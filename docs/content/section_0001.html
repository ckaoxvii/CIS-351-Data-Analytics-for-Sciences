Understanding Files, Folders, and File Types

Working with Files in Windows and macOS

Introduction

A sound file management system is an important part of modern data science. Throughout this course, you will create, download, open, modify, and save many different types of files. Keeping these files organized makes it easier for you and your collaborators to locate data, understand your workflow, and reproduce your analyses.

In this chapter, we will introduce the basic terminology of file management and examine how files and folders are organized in Windows and macOS. We will also discuss file paths, file extensions, and a few practical conventions for keeping your work organized.

1. Files and Folders

What is a file?

A file is a named collection of information stored on a computer. A file might contain text, a spreadsheet, a picture, a program, or data used in an analysis.

Examples include:

  • lecture_notes.qmd — a Quarto document.
  • penguins.csv — a comma-separated values data file.
  • results.xlsx — an Excel workbook.
  • plot.png — an image.
  • analysis.R — an R script.

The filename helps you identify the file’s purpose. In many cases, the filename also includes a file extension, such as .csv or .xlsx, which indicates the file type.

What is a folder?

A folder is a container used to organize files and other folders. A folder inside another folder is often called a subfolder. Folders can be arranged in a hierarchy, allowing related files to be grouped together.

For example, a course might use a structure like this:

CIS_351/
├── Week_01/
│   ├── week_01_lecture.qmd
│   └── notes.pdf
├── Week_02/
│   ├── penguins.csv
│   └── week_02_lecture.qmd
└── Homework/
    └── assignment_01.qmd

This is a text representation of a folder structure. The exact appearance of folders and files differs between operating systems, but the basic idea is the same: folders help you organize related files.

Why organization matters

A consistent folder structure helps you:

  • Find files again after saving or downloading them.
  • Keep raw data separate from cleaned data, code, and results.
  • Avoid accidentally editing or overwriting the wrong file.
  • Share a project with classmates or collaborators.
  • Make your analysis easier to understand and reproduce.

For data analysis, it is especially helpful to keep all files for a project in one main project folder, with clearly named subfolders when needed.

2. Finding Files in Windows and macOS

Windows and macOS use different names for their main file-management applications.

  • Windows
  • macOS

In Windows, use File Explorer to browse folders, open files, copy or move items, and create new folders. You can open File Explorer from the taskbar or by searching for “File Explorer” from the Start menu.

A Windows computer commonly has drives identified by letters. The main drive is often C:. A path might look like this:

C:\Users\Alex\Documents\CIS_351\Week_01

The backslash (\) separates the folders in a Windows path.

In macOS, use Finder to browse folders, open files, copy or move items, and create new folders. Finder is available from the Dock.

The main storage volume is commonly accessed through the startup disk, and user files are often stored in the user’s home folder. A path might look like this:

/Users/alex/Documents/CIS_351/Week_01

The forward slash (/) separates folders in a macOS path.

A note about paths

A file path identifies where a file or folder is located. It is similar to an address: it tells the computer how to reach a particular item within the folder hierarchy.

For example, these paths refer to a folder named Week_01, but they use the conventions of different operating systems:

  • Windows: C:\Users\Alex\Documents\CIS_351\Week_01
  • macOS: /Users/alex/Documents/CIS_351/Week_01

The paths above are examples; the actual username and folder locations on your computer may differ.

Viewing the path in macOS Finder

Finder does not always show the full path to the current folder by default. To display the Path Bar:

  1. Open a Finder window.
  2. Click View in the menu bar.
  3. Select Show Path Bar.

The Path Bar appears at the bottom of the Finder window and shows the folders leading to the current location. This can help you confirm where a file is stored.

Common folders

You will often encounter folders such as:

  • Desktop — items placed on the desktop.
  • Documents — a common location for documents and personal projects.
  • Downloads — files downloaded from a browser or other application.
  • Pictures — images and photographs.

Windows and macOS may provide additional folders and cloud-storage locations. Do not assume that every computer stores files in exactly the same place. When saving work for this course, choose the appropriate course or project folder and check the location before saving.

3. File Names and File Extensions

What is a filename?

A filename is the name used to identify a file. For example, in week_01_lecture.qmd, the filename is week_01_lecture.qmd.

Good filenames describe the contents of a file and make it easier to distinguish one version or assignment from another.

For this course, use these conventions unless an assignment specifies otherwise:

  1. Use lowercase letters in filenames.
  2. Use underscores (_) instead of spaces to separate words.
  3. Choose names that describe the file’s contents.
  4. Include the appropriate extension.
  5. Avoid vague names such as stuff, newfile, or final_final.

For example, prefer week_02_lecture.qmd over Week 2 Lecture final.qmd.

What is a file extension?

A file extension is the suffix at the end of a filename, usually consisting of a period followed by letters. It often indicates the file’s format or the application commonly used to open it.

Examples:

Extension Common file type Typical use
.txt Plain-text file Notes or unformatted text
.pdf Portable Document Format Documents designed to preserve layout
.docx Microsoft Word document Word-processing documents
.xlsx Microsoft Excel workbook Spreadsheets with worksheets and formulas
.csv Comma-separated values Tabular data stored as text
.png PNG image Screenshots, figures, and other images
.jpg or .jpeg JPEG image Photographs and other compressed images
.html HTML document Web pages
.R R script Code written in R
.qmd Quarto Markdown document Source document that can be rendered to formats such as HTML or PDF

An extension is a useful clue, but it does not guarantee that a file is valid or safe. Also, changing a filename’s extension does not convert the file to a different format. For example, renaming data.csv to data.xlsx does not turn a CSV file into an Excel workbook.

File extensions and applications

Different applications work with different file formats. For example:

  • You can use Excel to open an .xlsx workbook.
  • You can open a .csv file in Excel or a text editor.
  • You can edit an .R file in a code editor such as Positron or RStudio.
  • You can write a .qmd file in a Quarto-compatible editor and render it into an output format.

Some file types can be opened by more than one application. Your computer’s default application determines which app opens a file when you double-click it. You can usually choose another application from the file’s context menu.

4. Showing File Extensions

Some computers hide familiar file extensions in their file-management windows. As a result, you might see penguins rather than penguins.csv. Showing extensions makes it easier to identify file types and confirm that files have the expected names.

  • Windows
  • macOS

In current versions of Windows 11:

  1. Open File Explorer.
  2. Select View.
  3. Select Show.
  4. Turn on File name extensions.

The full filenames should now display extensions such as .csv, .xlsx, and .qmd. The precise menu layout may vary by Windows version.

To show extensions in Finder:

  1. Open Finder.
  2. In the menu bar, select Finder and then Settings (called Preferences in some older macOS versions).
  3. Open the Advanced section.
  4. Enable Show all filename extensions.

Finder should now display extensions for files when they are available. The precise wording may vary by macOS version.

Important caution when renaming files

When renaming a file, be careful not to remove or change its extension unintentionally. If you change penguins.csv to penguins.txt, the file’s contents may still be CSV data even though its name now suggests a text file. Some applications may no longer recognize the file as expected.

To convert a file, use the appropriate application’s Save As or Export function rather than simply changing the extension.

5. Creating and Managing Folders

A simple folder structure can make course work easier to manage. For example, you might keep each week’s lecture materials and data in a separate folder, or use a project folder with subfolders for data, scripts, and outputs.

  • Windows
  • macOS

In File Explorer:

  1. Navigate to the location where you want the folder.
  2. Right-click an empty area of the folder window.
  3. Select New and then Folder.
  4. Type a name and press Enter.

You can also use the New button in File Explorer when it is available.

In Finder:

  1. Navigate to the location where you want the folder.
  2. Open the File menu and select New Folder, or use the Finder’s available New Folder command.
  3. Type a name and press Return.

You can also create a folder from the context menu in many Finder views.

Moving and copying files

Copying creates another copy of a file or folder, while moving changes its location. Both operations are available through the file manager’s menus and keyboard shortcuts.

Before moving or renaming files used in a data analysis project, consider whether another file refers to their original locations. For example, a script that reads data/penguins.csv may stop working if you move the CSV file without updating the script or its path.

Keep project files together

For reproducible work, it is often best to keep related data, code, and documentation in a common project folder. A project might look like this:

penguin_analysis/
├── data/
│   └── penguins.csv
├── scripts/
│   └── clean_data.R
├── reports/
│   └── analysis.qmd
└── output/
    └── summary_table.csv

This is only an example. Use a structure that fits the project and any instructions provided for the course. Avoid creating many layers of folders unless they make the project easier to navigate.

6. Practical File-Management Habits

Good file management is not just about knowing where files are stored. It also involves developing consistent habits.

  • Check where you are saving. Before saving or downloading a file, confirm the destination folder.
  • Use descriptive names. A name such as penguin_bill_lengths.csv is more informative than data2.csv.
  • Keep raw data unchanged. When possible, preserve the original data and save cleaned or modified versions separately.
  • Separate inputs from outputs. Keep source data, scripts, reports, and generated results organized.
  • Use consistent naming conventions. Lowercase filenames and underscores can make names easier to work with in code.
  • Be careful with extensions. Do not assume that renaming a file changes its format.
  • Check paths when something goes wrong. If an application cannot find a file, verify the folder location and filename.

These habits help prevent common errors and make it easier for other people to follow your work.

Summary

Files store information, while folders organize files and other folders into a hierarchy. Windows uses File Explorer and commonly represents paths with drive letters and backslashes; macOS uses Finder and commonly represents paths with forward slashes. A file path identifies an item’s location, and a file extension often indicates its format or the applications that can open it.

For this course, use descriptive filenames, lowercase letters, and underscores as word separators. Keep related project files organized, check where you save them, and remember that changing a file’s extension does not convert its contents to another format.
